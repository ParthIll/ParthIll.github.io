Projects

GPT from scratch

Python · PyTorch

Around thirty small modules that stack up into a working GPT. It starts well below the model: a single neuron, backprop by hand, an MLP, activations and losses, before any of it touches PyTorch. Then embeddings, positional encoding, a self-attention head, multi-head attention, a transformer block, layer / batch / RMS norm, a BPE tokenizer and a batched loader, and finally a training loop and a generation script.

The two I'd single out are both on the inference side. KV-caching stores the keys and values you already computed so each new token attends over the cache instead of re-running the whole sequence. Grouped query attention shares one key/value head across several query heads, which is mostly a memory argument — you keep the query heads and shrink what you have to hold onto. Neither is complicated once you see it. Both took me a while.

This was built by working through the NeetCode ML course, one problem at a time. The code is mine, the curriculum wasn't, and the repo says so.

Ball Knowr

React Native · Expo · AsyncStorage

A basketball stat app for pickup games. You track a game live and it works out VORP, BPM, true shooting, eFG and game score on the phone, then ranks sessions on a leaderboard you can sort by any of them. No account, no backend, nothing leaves the device.

The awkward part is that VORP and BPM aren't really single-game stats. They're season-level regression formulas measured against a league baseline, so I had to write proxies for them: estimate possessions from the box score, scale impact to per-36 with a pace factor, and measure against a replacement level of −2. I capped BPM at ±20 and VORP at ±3, because a good ten minutes in a pickup game will otherwise produce a number that says you're the best player alive.

The part I'd actually point at is that the app won't show you a rating it doesn't trust. If minutes weren't logged there's no denominator for any of it, so the metrics get flagged unreliable and it shows the plain box score instead of printing something authoritative-looking and wrong.

Face detection with age and gender

TypeScript · Angular · TensorFlow.js · face-api · NgRx

Finds every face in a webcam feed about ten times a second and draws a box around each one with an age estimate and a gender guess, with the confidence printed next to it rather than hidden. Three models run per frame: the tiny face detector, the age/gender net and the 68-point landmark net.

Nothing is fetched at runtime. The detector weights and all three TensorFlow.js WASM binaries — plain, SIMD, and threaded SIMD — are bundled into the app, so "no video leaves your machine" isn't a promise about a server I run, it's that there's no network call to make. Startup tries the WASM backend first and falls back to WebGL and then CPU if the browser won't give it SIMD or threads.

URL shortener

Python · Flask · PostgreSQL · Redis · Docker

Built this to learn the infrastructure, not for the idea. The short code is the row's Postgres ID in base62, which is the part I liked: on a cache miss you decode the code back into the ID and look the row up by primary key, so there's no second index and no random-string collision check. Redis sits in front as a cache-aside layer, and IP rate limiting is a single Redis pipeline so the increment and the expiry land together.

Three services in Docker Compose. The web container waits on health checks — pg_isready and a Redis ping — instead of a sleep, which is the difference between it coming up and it coming up most of the time.
